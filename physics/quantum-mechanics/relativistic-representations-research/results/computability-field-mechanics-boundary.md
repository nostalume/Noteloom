# Computability and field--mechanics boundary

Status: supported exact response calculus; computational advantage remains
conditional

No fixed representation-theoretic procedure discovers a useful reduction for a
general Hamiltonian. Hidden algebras, angular separation, exact poles, stable
shells, projected resolvents, and collective closure each require problem-specific
structure. A smaller carrier or invariant notation is not computational leverage
unless discovery, construction, reduced solve, observable recovery, and error are
jointly cheaper.

The reusable common object is a response relative to `(H,P,O)`, not a universal
equation-solving method. Bound states, stable particles, resonances, scattering,
infraparticles, and collective modes require different spectral/asymptotic
witnesses. The branch therefore stops at a portfolio of admissible reductions and
explicit refusals rather than generalizing special integrable examples.

The mathematical unification is the irreducible observable return. For a typed
dynamical generator `L`, retained projection `P`, `Q=1-P`, departure `B=QLP`, and
return `C=PLQ`, it is

```text
Sigma_P(z)=C(z-QLQ)^(-1)B,
K_P(t)=C exp(t QLQ)B.
```

The resolvent and memory constructions preserve the same retained response. In the
self-adjoint Hamiltonian branch, `C=B^dagger` and they are transforms of the same
positive visible measure. In general classical or collective Liouville dynamics,
the return kernel remains exact but positivity need not transfer.

After a split `L=L_0+gV`, the Neumann expansion of the unresolved propagator
generates ordered excursion diagrams. Classical mechanics evaluates them as
Poisson/response words or trees; quantum mechanics as transition paths; a quasifree
graded field realization refines them into Wick/Feynman graphs. These are different
evaluation languages of one observable-return calculus, not identical physical
theories. The construction becomes computationally stronger than textbook
reformulation only when algebraic/observable quotienting removes or reuses diagrams
before their expensive realization.

The first spin-two graph probe sharpens that boundary. A curvature-created source
`J_e=K_2^dagger e` obeys `T J_e=0`, so the generated adapter
`M_2^(-1)=I-UT/4` acts as the identity. Its order-`g^2` detector return is therefore
a valid observable-quotient regression but cannot demonstrate reuse of the source
repair. On the off-shell invariant source cell spanned by `U sigma` and
`P_p^2 Q_p^(-1)sigma`, exact kernel computation instead generates a conserved
source with nonzero trace. The same edge coefficient changes from `6` without
adaptation to `-3` with the generated adapter. This supports a reusable
algebra-to-edge normal form; it does not yet support graph-enumeration advantage or
a physical scattering prediction, because the probe source is nonlocal and
singular on the null shell.

The local transfer is stronger but still conditional. For scalar on-shell momenta
`p,p'`, contracting the cheapest symmetric bilinear with `q=p'-p` leaves the
residual `(s-m^2)P_q`; the metric channel cancels it with coefficient `-1/2` and
generates a conserved local spin-two vertex. An identically conserved improvement
`P_q^2-UQ_q` remains, so neither representation theory nor conservation selects
the interaction uniquely. Once its coefficient is supplied by the matter action,
two typed vertices generate the three unordered pair partitions of four labelled
scalar legs, and every channel consumes the same compiled spin-two edge. This
supports the algebra/graph connector. Its fixed-kinematics leverage comparison is
reported next.

That fixed comparison is now complete for minimal coupling, equal unit masses,
center-of-mass momentum `1/2`, and right-angle transfer. The invariant compiler
returns numerator `11/4` and kernel coefficient `-11/2`; an independent de Donder

structural connection, provenance, and reuse—not tree-level computational
leverage. A stronger claim requires a bounded graph family in which orbit

The first loop continuation reveals a sharper constructive boundary before any

```text

This is a genuine algebra-to-graph operation and a possible source of
pre-integration compression, but computational leverage remains open until the
complete packet cost is compared with direct action expansion.

```

The formerly declared Green homotopy is now generated off the characteristic set.
For the spin-two gauge map `R_q`, contraction `A_q`, trace `T`, and momentum

```text

```

For `Q != 0` this gives complementary projectors
`P_g=R_q Q^(-1)F_q` and `P_t=I-P_g`. Dimension continuation reveals a hidden
restriction: `M_d=I-U T/2` obeys
`M_d^2=I+(d-4)U T/4`, so it is involutive only at `d=4`. Solving the inverse residual

```text

```

Using this inverse in the action pairing computes `K_q=Q P_t` at symbolic `d`,

```text
G_t=Q^(-1)P_t,

G_alpha=G_t+alpha R_q Q^(-2)F_q.
```
