Consumes: node 11's visible measure and node 18's observable-return/excursion

Produces: either a same-Hamiltonian bound/open return compiler with a complete-cost

## Capability and tension

The worktable separately computes a bound/open spectral response and compressed
open-tree events. Their common return is presently an explanation, not a retained
calculation. The missing capability is:

```text
one field Hamiltonian + one preparation
  -> generated B and M_B
  -> bound pole and residue
  -> open-channel amplitude
  -> identical projected resolvent
  -> comparison with full state-space solution.
```

Two alternatives are live:

1. in a single continuum channel, the operator-valued visible measure retains all
   coupling information needed by both bound and elastic open observables;
2. the open observable needs phase or channel information discarded by `M_B`, so
   the measure unifies transforms but cannot generate scattering.

The probe must distinguish them by constructing both observables from the same
measure and comparing them with the unreduced Hamiltonian. Merely writing their
known formulas would not decide the tension.

## Internally construct the bench Hamiltonian

Start from one discrete field mode `a` coupled number-conservingly to continuum
modes `b_omega`:

```text
H=e_0 a^dagger a
 +integral_0^1 omega b_omega^dagger b_omega d omega
 +g integral_0^1 [v(omega)b_omega^dagger a
                  +conj(v(omega))a^dagger b_omega]d omega.       (32.1)
```

The total excitation number commutes with every term. Its one-excitation sector is
therefore invariant and is not an imposed truncation:

```text
X=C direct-sum L^2([0,1],d omega),
H(c,f)=(e_0c+g< v,f >, omega f+gcv).             (32.2)
```

Prepare the discrete excitation with `Jc=(c,0)`, let `P=JJ^dagger`, and set
`Q=1-P`. Direct application of (32.2) constructs

```text
B=QHJ,              Bc=gcv,
QHQ=M_omega,
M_B(Delta)=B^dagger E_(M_omega)(Delta)B
            =g^2 integral_Delta |v(omega)|^2 d omega.            (32.3)
```

No dressed eigenvector or continuum wavefunction has been solved to obtain this
measure.

## Construct the common return

Solving the `Q` block of `(z-H)(c,f)=(eta,0)` gives

```text
f(omega)=gcv(omega)/(z-omega),

Sigma(z)=integral dM_B(omega)/(z-omega),
G_P(z)=J^dagger(z-H)^(-1)J
      =[z-e_0-Sigma(z)]^(-1).                   (32.4)
```

This is both a direct elimination and a reconstruction certificate for node 18's
Schur return. Repeated excursions do not need separate graphs:

```text
G_P(z)=G_0(z) sum_(n>=0)[Sigma(z)G_0(z)]^n,
G_0(z)=(z-e_0)^(-1).                            (32.5)
```

Thus every return graph at fixed `z` is compressed to one scalar transform of
`M_B`; equation (32.5) supplies the exact recovery map and its convergence
boundary `|Sigma G_0|<1`.

For the frozen flat bench `v(omega)=1`, `e_0=-1/2`, and `g=1/4`, (32.3) gives

```text
dM_B(omega)=g^2 1_[0,1] (omega)d omega,
Sigma(z)=g^2 log[z/(z-1)]                       (32.6)
```

on the real branch outside the band, continued from the upper half-plane inside
it.

## Compute the bound and open outputs

A bound pole `E_b<0` is generated by the zero of the same denominator:

```text
D(z)=z-e_0-Sigma(z),
D(E_b)=0,
Z_b=[1-Sigma'(E_b)]^(-1).                       (32.7)
```

For `E in (0,1)`, the boundary of (32.6) is

```text
Sigma(E+i0)=g^2 log[E/(1-E)]-i pi g^2.
```

Solving the stationary incoming-channel equation constructs the on-shell return

```text
T(E)=g^2/[E-e_0-Sigma(E+i0)],
S(E)=1-2pi i T(E).                              (32.8)
```

Writing `x=E-e_0-g^2 log[E/(1-E)]` computes

```text
S(E)=(x-i pi g^2)/(x+i pi g^2),
|S(E)|^2=1.                                     (32.9)
```

The common target for both routes is the projected resolvent (32.4). The executable
bench must compare its pole, residue, off-axis values, and continuum boundary with
a direct finite-mode Hamiltonian approximation at matched quadrature resolution.

The flat bench returns

```text
E_b=-0.5637634916846831,
Z_b=0.9337988784207747,
|D(E_b)|=3.05e-14,

S(1/4)=0.8912100120108271-0.4535909109447206 i,
||S(1/4)|^2-1|=2.22e-16.                       (32.10)
```

Both results carry the same visible-measure identifier. For midpoint continuum
resolutions `N=(16,32,64,128,256)`, the projected-resolvent errors are

```text
(2.979e-4, 7.437e-5, 1.859e-5, 4.647e-6, 1.162e-6),              (32.11)
```

showing the expected quadratic convergence on the chosen off-axis query. At
`N=256`, direct inversion of the `(N+1)`-mode Hamiltonian and its Schur return differ
by `3.14e-16`.

The dense route has the cubic proxy cost `16,975,361`, whereas the visible return
uses `770` primitive quadrature/assembly operations. But a competent baseline also
recognizes the arrowhead Hamiltonian and performs the same `770`-operation Schur
reduction. The construction therefore compresses the state space semantically and
beats full diagonalization, but supplies no new computational leverage over the
fair structure-aware baseline.

## Frozen contract `C_return-v1`

Inputs are `(e_0,g,v,band,preparation,energies,tolerance,mode budget)` for the
number-conserving one-discrete/one-continuum-channel Hamiltonian above. The
candidate operation is

```text
CompileFieldReturn(request)
 -> B + visible measure/transform
    + projected resolvent
    + bound pole/residue
    + elastic T/S boundary and unitarity residual
    + direct/reduced comparison and complete cost
 | refusal(no invariant sector, nonintegrable coupling, pole outside bracket,
           unmatched channel normalization, tolerance, or budget).
```

The candidate is supported only if the same generated measure recovers both
observables, direct finite-mode comparisons converge within declared tolerance,
and the reduced route uses asymptotically less work for those outputs. A pole or
open-channel mismatch rejects the matched region. Failure of cost leverage does not
reject correctness. A second continuum channel requiring off-diagonal channel
measures is an adversarial boundary, not an allowed amendment of `C_return-v1`.

## Horizon and stop rule

The horizon is the quadratic, number-conserving, one-excitation, single-channel
field model with compact continuum band, one bound pole, elastic boundary values,
and matched finite-mode certificates. It excludes multiparticle production,
infrared dressing, loops, and the claim that general interacting Hamiltonians are
tractable.

Stop and synthesize after the analytic identities, one convergent finite-mode
family, one unitarity check, one budget refusal, and the complete route-cost model
are classified. Further energy samples cannot promote generality. Re-enter only
for a structurally distinct post-freeze transfer or an information-loss
counterexample.

Those stop conditions are met. The replayable verdict is owned by

model are parked.
