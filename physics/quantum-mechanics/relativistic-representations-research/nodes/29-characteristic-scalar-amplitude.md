## Obstruction: the useful representative is singular on its target

For a photon subset `S`, construct

```text
q_S=p+sum_(i in S)k_i,       D_S=m^2+<q_S,q_S>,
G_S=D_S^(-1).
```

Node 27's open-line recurrence is

```text
A_empty=G_empty,

A_S=G_S[
  sum_(i in S)V_i(q_(S-{i}))A_(S-{i})
 +sum_({i,j} subset S)C_(ij)A_(S-{i,j})].       (29.1)
```

The desired characteristic class has `D_empty=D_I=0`. Evaluating (29.1) and then
amputating is therefore the wrong computational order: it constructs two inverses
that the output must immediately cancel.

## Generate the amputated transfer

Let `L_S=D_empty A_S`. The transition/contact bracket in (29.1) is linear in
earlier amplitudes, so applying `D_empty` to both sides computes

```text
L_empty=D_empty G_empty=1,

L_S=D_S^(-1)[
  sum_(i in S)V_i(q_(S-{i}))L_(S-{i})
 +sum_({i,j} subset S)C_(ij)L_(S-{i,j})].       (29.2)
```

For the full label set `I`, apply the second amputation before division:

```text
M_I=D_I L_I
   =sum_(i in I)V_i(q_(I-{i}))L_(I-{i})
    +sum_({i,j} subset I)C_(ij)L_(I-{i,j}).     (29.3)
```

Thus (29.3) never constructs `D_empty^(-1)` or `D_I^(-1)`. It inverts only
`D_S` for nonempty proper subsets. Induction on `|S|` in (29.2) gives
`L_S=D_empty A_S`; substituting `S=I` into (29.3) then gives the exact recovery

```text
M_I=D_empty D_I A_I.                            (29.4)
```

This is amputation as a generated boundary condition on the recurrence, not a
post-processing multiplication of a singular result.

## Compute the characteristic Ward quotient

Let `W_i` replace `epsilon_i` by `k_i`. Node 27 constructs the endpoint identity

```text
W_i A_I(p)=A_(I-{i})(p)-A_(I-{i})(p+k_i).       (29.5)
```

Because `W_i` changes polarization but not the endpoint kernels, applying it to
(29.4) computes both routes in the same expression ring:

```text
W_i M_I
 =D_empty D_I[A_(I-{i})(p)-A_(I-{i})(p+k_i)]
 =D_I [D_empty A_(I-{i})(p)]
  -D_empty[D_I A_(I-{i})(p+k_i)].               (29.6)
```

The two bracketed coefficients are generated by one-sided versions of (29.2).
The second needs no new history traversal: reverse the line from `q_I` using
momenta `-k_j`, since

```text
V_(-k)(q+k)=<2(q+k)-k,epsilon>
            =<2q+k,epsilon>=V_k(q),             (29.7)
```

and the pair contact is unchanged. Equation (29.6) is therefore an explicit ideal
membership witness

```text
W_i M_I in I_end=<D_empty,D_I>.                 (29.8)
```

Hence `[M_I]` in the proper-channel localization modulo `I_end` is independent of
every longitudinal photon representative. When both endpoint generators vanish,
the executable contraction itself vanishes. This instantiates node 24's descent
law; it does not repair node 24's separate scalar--spin-two threshold window.

## Generate the smallest positive readout

An amplitude class is not yet an event. Supply the preparation by the signed
external momenta and polarization representatives already used by `M_I`, and let
`w_Delta>=0` be a detector density for one declared kinematic cell. The detector
normalization is physical input; neither representation theory nor the Ward
identity selects it.

The readout is admissible only after calculating

```text
D_empty=D_I=0,                  scalar endpoint shells;
<k_i,k_i>=0,                    photon shells;
<k_i,epsilon_i>=0,              transverse preparation;
W_i M_I=0,                      gauge-quotient descent.
```

These conditions generate the positive fixed-event effect

```text
R_Delta=w_Delta |M_I|^2.                         (29.9)
```

Positivity is computed from the supplied sign and the complex modulus:

```text
w_Delta>=0 and |M_I|^2>=0  =>  R_Delta>=0.       (29.10)
```

It also factors through every polarization quotient. Replacing one representative
by `epsilon_i'=epsilon_i+alpha_i k_i` gives

```text
M_I(epsilon_i')-M_I(epsilon_i)
 =alpha_i W_iM_I
 =alpha_i(D_empty c_i^empty+D_I c_i^I)
 =0,

R_Delta(epsilon_i')-R_Delta(epsilon_i)
 =w_Delta(|M_I|^2-|M_I|^2)=0.                  (29.11)
```

The Ward compiler accepts arbitrary remaining polarization arguments, so applying
(29.11) successively handles simultaneous representative shifts without expanding
polarization components.

For a forward two-photon Lorentzian regression, take

```text
eta=diag(-1,1,1),  p=(1,0,0),
k=(1,1,0),         epsilon=(0,0,1),
(k_1,k_2)=(k,-k),  w_Delta=3/5.
```

All admission residuals vanish. The generated contact channel gives

```text
M_{1,2}=-2,        R_Delta=(3/5)|-2|^2=12/5.    (29.12)
```

This familiar case is a physical-semantics regression and correctly has no route
advantage. A non-collinear five-photon exact shell fixture instead produces

```text
M_I=-28804317/238051,
R_Delta=829688677836489/56668278601,             (29.13)
```

with zero shell, transversality, and Ward residuals. This is the transfer witness:
the cost crossover survives after the compressed amplitude is consumed by the same
positive prepared-event readout.

## Complete combinatorial cost

Let `E_N` count singleton and contact transitions in the subset recurrence and
`B_N` count event applications in explicit histories:

```text
E_N=N 2^(N-1)+binom(N,2)2^(N-2),

B_N=sum_r h_(N,r)(N-r).
```

Certifying all `N` Ward contractions uses one contracted `N`-label transfer and
two `(N-1)`-label one-sided transfers per photon:

```text
C_N=N(E_N+2E_(N-1)),       T_N=E_N+C_N.         (29.14)
```

The generated cost certificate gives

| photons | explicit `B_N` | amplitude `E_N` | with Ward certificate `T_N` |
| ---: | ---: | ---: | ---: |
| 4 | 216 | 56 | 424 |
| 5 | 1,830 | 160 | 1,520 |
| 10 | 518,578,200 | 16,640 | 321,280 |

Thus ordinary use is cheaper at four photons, but the conservative route that
re-certifies every Ward law becomes cheaper only at five. These are exact
combinatorial operation counts. They do not count symbolic expression growth,
analytic continuation, phase-space integration, or infrared completion.

The event readout adds the same two scalar operations—modulus square and detector
weight—to both routes. The two-photon regression therefore costs `7` baseline
operations against `21` compiled operations. The five-photon transfer costs
`1,832` against `1,522`, so the whole prepared-event route retains the first
strict advantage rather than moving work into observable recovery.
