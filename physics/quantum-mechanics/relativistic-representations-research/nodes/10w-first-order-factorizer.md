# N10w — First-order factorizer and generated Clifford action

Status: supported on the declared four-dimensional complex bench  
Kind: construction + executable semantic computation

## Spine binding

- **Upstream anchor:** N2b supplies the complex chiral Lorentz carriers and the
  metric; N10m needs one coefficient action before it can generate the
  half-integer grammar.
- **Bridge question:** can that action be generated from a propagation capability
  rather than imported as the Clifford anticommutator?
- **Invariant target:** a Lorentz-equivariant first-order symbol whose two-step
  propagation is the same scalar wave symbol `Q(p)` used by the bosonic branch.
- **Downstream effect:** the returned action is now the only generative input by
  which N10m admits `L`, `G`, and the half-integer residual constructor.
- **Horizon:** complex four-dimensional chiral carriers with a dimension-four
  parity-paired budget.  General Clifford-module classification, real structures,
  positivity, and CAR quantization are outside this node.

## Capability and cheapest candidate

The input is a metric vector carrier `(V,eta)` and a request for a symbol

```text
d: V* -> End(Delta)
```

that is Lorentz equivariant, linear in momentum, and completes twice to the scalar
wave symbol:

```text
d(p)d(p)=Q(p) I,       Q(p)=eta^(-1)(p,p).
```

Linearity is the cheapest first-order candidate.  The obstruction is exposed by
evaluating the same completion at `u+v` and subtracting the evaluations at `u`
and `v`:

```text
d(u+v)^2-d(u)^2-d(v)^2
  =d(u)d(v)+d(v)d(u),

Q(u+v)-Q(u)-Q(v)
  =2 eta^(-1)(u,v).
```

Both lines have the same input `(u,v)` and the same endomorphism target.  Therefore
scalar-wave completion forces

```text
d(u)d(v)+d(v)d(u)=2 eta^(-1)(u,v) I.
```

The relation is an output of polarization.  It is not supplied to the constructor.

## Universal repair and chirality obstruction

The tensor algebra is the free algebra generated by the vector input.  Killing the
calculated obstruction constructs

```text
Cl(V*,eta^(-1))
 =T(V*)/<u tensor v+v tensor u-2 eta^(-1)(u,v) 1>.
```

Its universal property retains a reusable tool: every linear metric-square
factorization descends uniquely through this quotient.

In four complex dimensions N2b gives `V_C ~= S tensor Sbar`.  A vector action
changes chirality:

```text
d_+(v):S -> Sbar,
d_-(v):Sbar -> S.
```

Consequently a vector symbol cannot be an endomorphism of `S` alone.  For a
parity-paired endomorphism request, the obstruction forces

```text
Delta=S direct-sum Sbar,
d(v)=d_+(v) direct-sum d_-(v)
```

in off-diagonal form.  A same-chirality request is refused; a Majorana request is
also refused unless a compatible conjugation/intertwiner is supplied.

## Retained interface

```text
FirstOrderFactorizer(metric, capability, chiral carrier,
                     module request, resource budget)
  -> coefficient module,
     equivariant symbol space,
     universal quotient,
     generated action,
     square/polarization/chirality certificates,
     or typed refusal.
```

The executable realization is
[`first-order-factorizer.mjs`](../computation/10w-first-order-factorizer/first-order-factorizer.mjs),
with checks in
[`check-first-order-factorizer.mjs`](../computation/10w-first-order-factorizer/check-first-order-factorizer.mjs).
N10m rejects a handcrafted quadratic action and consumes only the generated
origin certificate.

## Checks and boundary

The bench verifies the square and polarization identities as retained semantic
computations and checks the refusal boundary.  It does not claim that the metric
alone selects a physical fermion: parity, reality, positive-frequency completion,
and CAR statistics remain separately typed resources.

## Edges

```text
N2b metric and chiral carriers
  -> N10w generated coefficient action
  -> N10m natural-operation grammar
  -> N10b/N10g half-integer field and source constructors
  -> spin-3/2 regression in the manuscript.
```
