# Residual and repair compiler

Status: generated inside supplied bounded grammars

## Capability

Given a candidate gauge/equation word, calculate why it fails and generate the
smallest admissible correction, constraint, compensator, source adapter, or refusal.

## Construction

Input is a grammar produced by node 13, a typed carrier
rank, candidate maps `R_0,D_0`, preserved carrier conditions, and a resource budget.
Compute rather than predict the obstruction:

```text
r = N(D_0 R_0).
```

Expand an admissible correction basis `b_i` generated by the grammar,

```text
D = D_0 + sum_i c_i b_i,
```

then reduce

```text
N(DR_0)=r+sum_i c_i N(b_i R_0).
```

Collecting independent normal words produces an exact linear system over `QQ`.
Solving it generates coefficients and detects inconsistency or free parameters.

## Repair branches

- If the solution cancels every channel, return the generated field operator.
- If cancellation requires a parameter condition, return that constraint with the
  failed channel.
- If a new field can absorb the residual, construct its transformation and coupled
  equation as a compensator.
- Pairing or adjoint residuals generate a source adapter/Euler multiplier by the
  same solve, not by reusing a memorized formula.
- Fermionic residuals use bounded Clifford normal words; bosonic and fermionic
  outputs share the same result/refusal type.

## Internal proof

The compiler returns exact certificates:

```text
normal_form(DR)=0,
normal_form(source compatibility residual)=0,
normal_form(Euler adjoint residual)=0,
```

plus coefficient domain, rules used, rank, unresolved words, and provenance. A
downstream consumer can use `D`, `R`, and the adapter without replaying the proof.

## Retained interface

```text
ResolveResidual(grammar, request, budget)
  -> generated maps + constraints + certificates + provenance
  | refusal(reason, residual channels, required resources)
```

Regression covers scalar/vector/spin-two and spin-1/2/spin-3/2 families. Transfer
across symmetric and Clifford grammars demonstrates more than one-formula checking.

## Edges and boundary

- [Bosonic](06-bosonic-free-field-machine.md) and [fermionic](07-fermionic-free-field-machine.md)
  machines consume generated maps.
- [Carrier/source boundary](15-carrier-source-obstructions.md) compares alternative
  presentations on the same response.

Completeness is only relative to the generated finite basis and budget. Interaction
consistency and arbitrary mixed symmetry are not inferred.
