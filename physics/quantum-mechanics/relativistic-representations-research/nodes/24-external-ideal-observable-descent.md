## Construct the descent criterion

Let `V` be the packet module and let

```text
q:V -> V/I_ext
```

be the quotient map. Node 19 supplies a packet `Pi` whose gauge variation satisfies

```text
delta Pi=E(p_L)Y_L+E(p_R)Y_R in I_ext.          (24.1)
```

A proposed detector is a linear map `O:V->Y`. It is independent of the chosen
representative exactly when there is a map `bar O` satisfying

```text
O=bar O circle q.                               (24.2)
```

This condition is constructed rather than named. If (24.2) holds and `i` belongs
to `I_ext`, then

```text
O(i)=bar O(q(i))=bar O(0)=0.                    (24.3)
```

Conversely, suppose `O(I_ext)=0`. Define

```text
bar O([v])=O(v).                                (24.4)
```

If `[v]=[v']`, then `v-v'` lies in `I_ext`, and evaluation on that same difference
computes

```text
O(v)-O(v')=O(v-v')=0.                           (24.5)
```

Thus (24.4) is well defined and satisfies (24.2). The compiler admission law is
therefore

```text
O descends to V/I_ext    iff    I_ext subset ker O.          (24.6)
```

Applied to (24.1), this gives `O(delta Pi)=0` without selecting a gauge.

## The finite window does not descend

On the diagonal two-point channel put

```text
x=E(p)=s-mu,       x>=0.
```

A finite spectral window acts on a test kernel `f` by

```text
W_Delta(f)=integral_0^Delta f(x) d nu(x),        Delta>0,     (24.7)
```

where `nu` is a positive detector measure. The external ideal is generated by
`x`. Test (24.6) on the unit witness `f=1`:

```text
W_Delta(x)=integral_0^Delta x d nu(x).           (24.8)
```

If `nu` assigns positive mass away from `x=0`, (24.8) is positive. More strongly,
if (24.8) vanished, then for every `epsilon>0`, positivity would give

```text
epsilon nu([epsilon,Delta])
 <=integral_[epsilon,Delta] x d nu(x)
 <=W_Delta(x)=0.                                (24.9)
```

Hence `nu` would be supported entirely at the shell. A nontrivial positive
finite-width detector therefore cannot annihilate the ideal `(x)`. The only
positive quotient functional of this form is a shell atom.

Node 22 already found that the current measure has no isolated atom at `x=0`.
Consequently the bare two-point quotient offers two incompatible choices:

```text
shell evaluation
  -> descends, but has no nonzero pole weight;

finite-width response
  -> nonzero, but does not descend.                              (24.10)
```

## Compute the obstruction on the generated density

For node 23's four-dimensional density,

```text
rho(mu+x)=2mu[2x-mu+mu^2/(mu+x)].               (24.11)
```

The detector value on the ideal generator is not left as an abstract warning.
Multiplication by `x` and integration give

```text
K_mu(Delta)
 =integral_0^Delta x rho(mu+x) d x
 =2mu[2Delta^3/3-mu Delta^2/2
      +mu^2 Delta-mu^3 log(1+Delta/mu)].         (24.12)
```

Its integrand is positive for `x>0`, so `K_mu(Delta)>0`. Near the threshold,

```text
K_mu(Delta)=(2mu/3)Delta^3+O(Delta^4).           (24.13)
```

Dividing two window masses does not cancel this Ward obstruction. If
`F=J(Delta)/J(Lambda)`, its first variation along the same ideal direction is

```text
delta F
 =[K(Delta)J(Lambda)-J(Delta)K(Lambda)]/J(Lambda)^2.          (24.14)
```

Using `J(r)=mu r^2+O(r^3)` and `K(r)=2mu r^3/3+O(r^4)` computes

```text
delta F
 =(2/3)(Delta/Lambda)^2(Delta-Lambda)+higher terms,           (24.15)
```

which is nonzero for distinct small resolutions. Node 23's ratio cancels an
overall normalization, but not the external gauge ideal. It remains a useful
gauge-fixed spectral diagnostic rather than a physical observable of the present
bare packet.

## The obstruction generates an observable-repair compiler

Do not choose a dressing by name. Let the external grammar supply admissible
operations `C_1,...,C_n`: vertex/box completions, relational reference fields,
gravitational dressings, transformed detector operations, or asymptotic memory
effects. Evaluate every candidate on the same ideal basis:

```text
r=O(I_ext),
c_j=C_j(I_ext).
```

The physical effect must be generated by solving

```text
r+a_1 c_1+...+a_n c_n=0.                        (24.16)
```

When (24.16) has a solution within the resource budget, define

```text
O_phys=O+a_1 C_1+...+a_n C_n.                  (24.17)
```

Direct substitution returns `O_phys(I_ext)=0`, so (24.6) constructs a unique map
on the quotient for the selected solution. If the correction columns do not span
`-r`, the operation refuses instead of reporting a gauge-fixed number.

The workbench retains this interface as

```text
ObservableDescent(I_ext,O,external grammar,budget)
  -> direct quotient
   | compensated quotient + generated weights + zero residual
   | refusal + surviving ideal witness.                       (24.18)
```

The coefficients in (24.16) are generated by exact residual solving. They are not
hard-coded from a known dressed observable.

## The cheapest existing compensator fails on the cut

Node 20 already generated

```text
F_q R_q=Q I,       Q=q^2.                       (24.19)
```

Away from the characteristic set, this relation constructs a field-dependent
coordinate displacement

```text
V_q(h)=Q^(-1)F_q h.                             (24.20)
```

Evaluate it on a gauge displacement `delta h=R_q xi`:

```text
delta V_q
 =Q^(-1)F_q R_q xi
 =Q^(-1)Q xi
 =xi.                                           (24.21)
```

With node 19's convention `delta phi=kappa L_xi phi`, the first-order relational
scalar

```text
Phi=phi-kappa L_(V[h]) phi                       (24.22)
```

has variation

```text
delta Phi
 =kappa L_xi phi-kappa L_(delta V) phi+O(kappa^2)
 =0+O(kappa^2).                                 (24.23)
```

This is a genuinely generated external correction: the inverse in (24.20) is
forced by the failure of the local scalar to descend. But the active cut places the
spin-two momentum on `Q=0`, where (24.20) is undefined. The cheapest bulk homotopy
therefore refuses precisely on the soft characteristic sector that caused the pole
obstruction.

The failure is informative. A successful correction must carry boundary, soft, or
relational data not contained in the off-characteristic Green inverse. This is the
point at which memory-sector or asymptotic observable algebras rejoin the compiler,
not an invitation to insert a singular `Q^(-1)` prescription silently.

## Compiler architecture produced by the obstruction

The graph route now has two different repair layers:

```text
vertex/edge grammar
  -> internal Ward residual
  -> action-jet contact repair
  -> packet modulo I_ext

packet modulo I_ext + detector request
  -> detector value on I_ext
  -> external-operation repair
```

The first layer makes a valid Green-function packet. The second makes a physical
observable. Conflating them was the hidden gap between nodes 19 and 23. This
two-layer interface is reusable in gauge theories beyond the current spin-two
example; only the ideal generators and admitted correction grammar change.
