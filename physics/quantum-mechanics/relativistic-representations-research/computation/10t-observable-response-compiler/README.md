annihilators of N10j's curvature operation. It does not receive the visible layer
or response formula. Since `K_s P=K_s U=0`, it calculates `K_s R_(s-1)=0` and
therefore removes every raised layer `l<s`. The unique remaining layer has
`B_s=0`, so both constrained and compensated source routes normalize to

```text

```

The retained operation constructs and caches that boundary-selected curvature
response once per source. A batch of curvature functionals reuses it; increasing
the number of functionals does not create a presentation-specific advantage.

records the formal potential/curvature channel crossover, the pointwise visible
source-layer dimension without treating it as an implemented minimal coordinate
system, and a
regularized spectral stress test. The latter demonstrates why an implementation
should fuse the derivative and Green symbols instead of materializing a large
order-`s` intermediate. It is a floating-point range regression, not a physical
ultraviolet or runtime theorem.
