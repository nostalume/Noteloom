# Observable-Dynamics Reduction Contracts

Recorded: 2026-08-30  
Used by: [visible spectral measure](../nodes/11-visible-spectral-measure.md)

This packet binds theorem-scale projection and domain boundaries. node 11 constructs
the linear quotient criterion, Duhamel memory equation, resolvent self-energy, and
all same-input branch comparisons internally.

## OD-01 — Projection produces an exact memory equation

- **Sources:** Guy Cohen and Eran Rabani, [Memory Effects in Nonequilibrium
  Quantum Impurity Models](https://arxiv.org/abs/1105.5348); Andres
  Montoya-Castillo and David R. Reichman, [Approximate but Accurate Quantum
  Dynamics from the Mori Formalism: I. Nonequilibrium
  Dynamics](https://arxiv.org/abs/1603.01903).
- **Inputs consumed:** a full Liouville evolution, a declared projection onto
  retained variables, its complementary dynamics, and compatible initial data.
- **Output consumed:** the retained quantum state satisfies an exact generalized
  master equation containing an instantaneous term, an initial-correlation term,
  and a memory kernel generated by the complementary dynamics.
- **Internal use:** node 11 derives the bounded linear identity directly from the two
  projected differential equations. These sources confirm its role as the exact
  reduced-dynamics baseline and the dependence of memory on the selected
  projection.
- **Boundary:** an exact memory equation is not automatically Markovian or cheaper.
  Evaluating the projected propagator or kernel can retain the full many-body
  problem; short memory and stable approximation require separate estimates.

## OD-02 — Formal closure may retain the original computational burden

- **Source:** Ayoub Gouasmi, Eric Parish, and Karthik Duraisamy, [A Priori
  Estimation of Memory Effects in Coarse-Grained Nonlinear Systems Using the
  Mori--Zwanzig Formalism](https://arxiv.org/abs/1611.06277).
- **Inputs consumed:** resolved and unresolved variables for a nonlinear dynamical
  system, with a projection acting on the associated Liouville evolution.
- **Output consumed:** unresolved dynamics can be represented by a memory integral
  and initial-data/noise term, while the orthogonal dynamics needed to evaluate
  that memory remains a high-dimensional problem in general.
- **Internal use:** node 11 consumes only the negative computational boundary: exact
  semantic closure does not prove whole-route compression.
- **Boundary:** the paper's pseudo-orthogonal approximation and fluid examples are
  not imported into the field/mechanics or quantum-chain branches.

## OD-03 — Resolvent memory and state recovery require operator hypotheses

- **Contract reused:** [GC-01 isospectral sector
  elimination](global-computability-contracts.md#gc-01--isospectral-sector-elimination)
  and [FM-01 exact sector elimination and
  recovery](field-mechanics-variation-contracts.md#fm-01--exact-sector-elimination-and-recovery).
- **Inputs consumed:** complementary projections, a closed generator or
  Hamiltonian, invertibility of the eliminated block at the spectral parameter,
  and domain-compatible composites.
- **Output consumed:** the Schur/Feshbach resolvent denominator and its full-state
  recovery map are valid under those hypotheses.
- **Internal use:** node 11 derives the block identity on bounded maps and uses these
  contracts only when identifying it with node 09's unbounded field Hamiltonian.
- **Boundary:** thresholds, resonances, unbounded generators, and nonlinear
  reductions require their own domain, boundary-value, or semigroup theorems.

## Supported boundary

The contracts support the shape

```text
declared retained variables
  -> exact instantaneous + initial-correlation + memory evolution
  -> Markov closure only after an additional decay/scale estimate.
```

They do not select the physically relevant variables, guarantee short memory, or
turn an exact projected equation into a cheaper algorithm.
