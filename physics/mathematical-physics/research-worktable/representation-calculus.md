# Representation-first spectral calculus

## Capability

Construct differential spectral data from representation operations, and recover
candidate representation structure from a *family* of differential operators and
intertwiners.  The retained output must be usable by a person through generators,
relations, branching, and matrix coefficients; coordinate expansion is only a
local certificate or final realization.

## Primitive package

```text
RepresentationCalculus = (
  group or local group G, subgroup K, Lie algebra g,
  smooth/algebraic representation (pi,V), analytic completion H,
  distinguished vectors and covectors Q,
  operator algebra A inside U(g) and its commutant C,
  branching/tensor rules B,
  matrix-coefficient constructor MC,
  analysis/synthesis maps, observable recovery,
  globality, domain, ambiguity, and failure certificates
)
```

The group is not sufficient by itself: `A` selects dynamics, `K` selects the
visible sector, and the distinguished vectors/covectors select the matrix
coefficients consumed by an observable.

## Generator 1: matrix coefficients become differential systems

For `v in V` and `ell in V^vee`, define

```text
MC(ell,v)(g) = ell(pi(g)v).
```

Let `R_X` be the right-invariant differential operator defined by

```text
(R_X f)(g) = d/dt|_0 f(g exp(tX)).
```

Both routes below have common input `(ell,v,g,X)` and common scalar target:

```text
R_X MC(ell,v)(g)
  = d/dt|_0 ell(pi(g exp(tX))v)
  = d/dt|_0 ell(pi(g)pi(exp(tX))v)
  = ell(pi(g)dpi(X)v)
  = MC(ell,dpi(X)v)(g).
```

Composition extends this operation from `g` to `U(g)`:

```text
R_u MC(ell,v) = MC(ell,dpi(u)v),  u in U(g).
```

If `z` is central and an irreducible representation has central character
`chi_pi`, Schur's lemma supplies the theorem contract `dpi(z)=chi_pi(z)I`.
Consequently,

```text
R_z MC(ell,v) = chi_pi(z) MC(ell,v).
```

The differential eigenvalue is therefore constructed from a central character;
the coordinate PDE is a later realization of `R_z`.

## Generator 2: subgroup visibility and spherical compression

If `v` is fixed by `K`, the appropriate matrix coefficient is right `K`-invariant
and descends to `G/K`.  If both sides are `K`-fixed, it is `K`-bi-invariant and
descends further to `K\G/K`.  For a Gelfand pair with

```text
dim(V_pi^K) <= 1,
```

the spherical channel is multiplicity-free.  A single normalized vector `v_pi`
then constructs

```text
phi_pi(g) = <v_pi, pi(g)v_pi>,  phi_pi(e)=1.
```

On a rank-one symmetric space the double-coset variable is one-dimensional, so
the invariant PDE reduces to a radial ODE.  This is a structural consequence of
`rank(G/K)=1`, not a separation-coordinate guess.

## Generator 3: symmetry removes representation factors

For a unitary decomposition

```text
H ~= integral^direct V_lambda tensor M_lambda dmu(lambda),
pi(g) ~= integral^direct pi_lambda(g) tensor I_Mlambda dmu(lambda),
```

an operator `T` in the commutant of `pi(G)` has the decomposable form

```text
T ~= integral^direct I_Vlambda tensor T_lambda dmu(lambda).
```

The spectral calculation is performed only on the multiplicity spaces
`M_lambda`.  If `T=dpi(z)` for central `z`, then `T_lambda` is already the scalar
`chi_lambda(z)`.  The spectrum and degeneracy are representation data; analytic
solution functions are needed only when the observable demands them.

## Human-normal form

The calculus returns the smallest relations from which consequences can be
regenerated:

| Retained representation object | Generated analytic information |
| --- | --- |
| central character | differential eigenvalue |
| root or ladder operator | recurrence and parameter shift |
| extremal/cyclic vector | initial solution sector |
| restriction along `G superset K` | separation labels and multiplicities |
| tensor product and coproduct | product/addition formulas |
| Clebsch–Gordan intertwiner | linearization coefficients |
| invariant pairing | orthogonality |
| matrix coefficient of `exp(tX)` | generating kernel |
| Plancherel decomposition | spectral measure and completeness |

These rows are constructors only when the named object and equality are supplied.
A three-term recurrence does not automatically prove a Lie-group origin.

## Inverse object: retain the arrows

A single scalar equation usually forgets the representation.  The inverse input is
therefore a differential family

```text
DifferentialFamily = (
  parameter objects a,
  operators D_a and analytic domains,
  intertwiners A_(a->b),
  pairings and transforms,
  tensor/product operations when present,
  observable and allowed equivalences
).
```

The inverse first constructs the category/algebra generated by the intertwiners:

```text
A_(b->c) A_(a->b), identities, adjoints, commutators, kernels, quotients.
```

It then asks whether this retained structure admits a Lie-algebra presentation,
integrates to a group, and has a compatible analytic representation.  Failure to
integrate globally, multiple covers, and distinct groups with the same local root
data remain explicit outputs.

## Structural discovery before coefficient search

For differential input, use the filtration

```text
principal symbol and Hamiltonian geometry
  -> invariant/Poisson centralizer
  -> candidate first-order generators
  -> commutator residual
  -> forced lower-order correction
  -> closed operator algebra or obstruction
  -> modules, branching, and analytic realization.
```

Only the residual correction should be expanded.  A blind generic ansatz is a
fallback bounded search, not the primary human derivation.

## Three computability certificates

Every promoted result records separately:

1. **construction:** how the algebra, module, or intertwiner was generated;
2. **execution:** how the requested spectrum or observable is calculated;
3. **human compression:** primitive count, relation count, semantic transformation
   depth, residual block size, coordinate-expansion depth, and the number of
   instance formulas replaced by the retained operations.

A computer can verify the certificate.  It does not own the meaning of the
construction.
