# Boundary representation reduction at fixed continuum accuracy

## 1. Why this benchmark exists

The preceding [boundary-domain benchmark](boundary-domain-symmetry-complexity.md)
proved an exact block reduction of one finite polynomial Ritz pencil. That did not
answer the harder computational question: does representation decomposition still
remove work when two methods approximate the same continuum observable to the same
tolerance and the unreduced method uses a sparse partial eigensolver?

This node compares

```text
observable: first K=6 eigenvalues, with multiplicity,
problem:    (-Delta,H^1_0(unit disk)),
tolerance:  maximum ordered relative eigenvalue error <= 2/25,
route A:    boundary-constructed SO(2) sectors + radial finite volume,
route B:    Cartesian five-point disk grid + sparse shift-invert eigensolve.
```

The Bessel zeros are a validation oracle for continuum error only. They do not
select rotation sectors, provide reduced equations, or determine when sector
generation stops. Sources [45--47](../sources.md) bind the oracle and numerical
substrates; the symmetry discovery, quotient construction, and frontier
certificate are internal.

## 2. From the boundary group to an orbit-space problem

The earlier constructor starts from the differential expression, domain, and
Dirichlet trace condition. Their joint stabilizer removes translations and retains
rotation. Once `SO(2)` is constructed, its irreducibles are characters
`exp(i m theta)`, and its invariant coordinate algebra is generated by

```text
s=x^2+y^2.                                                   (1)
```

Writing a weight-`m` function intrinsically as `u=z^m v(s)` for `m>=0` turns the
Dirichlet disk eigenproblem into

```text
-4 d/ds(s^(m+1) dv/ds)=lambda s^m v,
v(1)=0,                                                      (2)
```

with the natural finite-energy condition at `s=0`. Equation (2) is not supplied
as a preferred coordinate separation: the character and invariant variable are
outputs of the boundary-compatible action. A cell-centered flux discretization
therefore assembles one real symmetric tridiagonal problem per `|m|`, without
expanding a two-dimensional field component by component.

The multiplicity is representation data: `m=0` occurs once and every `m>0`
eigenvalue occurs twice, for the `+m` and `-m` characters.

## 3. Non-exhaustive sector generation

Solving every representation sector would merely relocate enumeration. The disk
quadratic form instead gives the lower bound

```text
lambda >= m^2.                                               (3)
```

Maintain the current `K`th computed value `U`. Generate weights in increasing
`|m|` and stop as soon as the first unconstructed sector satisfies

```text
(|m|_next)^2 > U.                                            (4)
```

For the accepted run, sectors `|m|=0,...,5` give

```text
U=30.55729011,     lower bound for |m|=6 is 36 > U.           (5)
```

Thus no unseen sector can enter the first six values. This is a short human
certificate, not an exhaustive list of special functions. The reference Bessel
zeros are absent from this stopping rule.

The transferable form is branch-and-bound on the dominant-weight lattice. If a
boundary-compatible compact-group action gives a coercive sector estimate

```text
lambda_min(pi) >= a C_2(pi)+b,                               (6)
```

then irreducibles outside the finite Casimir sublevel set can be rejected before
any reduced solve. Formula (6) is a required problem-specific certificate, not an
automatic fact for every operator.

## 4. Same-accuracy result

The exact continuum reference is

```text
5.78318596,
14.68197064, 14.68197064,
26.37461643, 26.37461643,
30.47126234.                                                  (7)
```

The first accepted resolution on each declared refinement schedule is:

| route | accepted resolution | active unknowns | assembled nonzeros | maximum relative error | maximum algebraic residual |
| --- | ---: | ---: | ---: | ---: | ---: |
| representation sectors | 16 radial cells, six constructed `|m|` sectors | 96 | 276 | `2.98e-3` | `3.58e-12` |
| Cartesian sparse baseline | 24 intervals across the diameter | 437 | 2,093 | `4.30e-2` | `2.52e-14` |

The 16-interval Cartesian attempt has maximum relative error `9.16e-2` and fails
the common target; its setup and solve time remain charged to the baseline. At the
first passing resolutions, the representation route uses `96/437 = 0.220` of the
active unknowns and `276/2093 = 0.132` of the stored scalar nonzeros. One observed
single-process run used roughly `0.12` of the baseline wall time, but this timing
ratio is deliberately not promoted to a portable complexity law.

The output status is `FixedAccuracyComparison` and the route verdict is
`RepresentationReductionAtTolerance`. An input whose tolerance is not reached by
either declared budget returns `UnresolvedAccuracyWithinBudget` and no winner.

## 5. The general complexity statement

Let an `n`-dimensional boundary problem admit a compact action with generic orbit
dimension `d`, hence quotient/cohomogeneity `q=n-d`. For mesh scale `h`, a full
discretization typically has

```text
N_full(h)=Theta(h^(-n)),
N_reduced(h,Lambda)=sum_(pi in F_Lambda) b_pi Theta(h^(-q)),  (8)
```

where `F_Lambda` is the sector frontier required by the spectral window and
`b_pi` includes finite multiplicity or internal-spin blocks. Representation
reduction is computationally useful only when the complete construction,
sector-solve, and recovery cost is smaller than the full route at the same error.

For the disk, `n=2`, `d=1`, `q=1`: the spatial discretization changes from a
two-dimensional grid to finitely many one-dimensional quotient problems. This is
the structural source of the gain. It also explains why symmetry need not reduce
a PDE all the way to an ODE: an axial action on a three-dimensional nonseparable
domain has `q=2` and produces two-dimensional sector PDEs.

Equation (8) is a cost grammar rather than a universal theorem. The size of
`F_Lambda`, sector conditioning, convergence constants, sparse fill, iterative
counts, and recovery demands must be measured or bounded for each operator/domain
pair.

## 6. What was eliminated, compressed, and left unpaid

| Stage | Verdict | Reason |
| --- | --- | --- |
| boundary-compatible group discovery | paid once | affine Killing fields are intersected with the boundary stabilizer |
| coordinate search | eliminated | the character and invariant `s` come from the constructed action |
| sector enumeration | compressed | one lower-bound frontier replaces an unbounded scan |
| spatial degrees of freedom | reduced | `437 -> 96` at the common tolerance |
| matrix nonzeros | reduced | `2,093 -> 276` |
| multiplicity recovery | paid | representation labels restore both character copies |
| continuum error | measured, not proved a priori | Bessel zeros are used as an external validation oracle |
| general solver superiority | unpaid | only the declared sparse Cartesian baseline is compared |

The benchmark therefore closes a first sparse, partial-spectrum, fixed-accuracy
bridge. It does not prove that radial reduction beats boundary-fitted finite
elements, spectral elements, multigrid, or every preconditioner. The Cartesian
baseline also represents the curved boundary by a staircase grid, and the 8%
tolerance is a probe rather than a high-accuracy study.

## 7. Next global transfer

The next decisive test should not be another spherical special-function example.
Use a three-dimensional axially symmetric but nonseparable domain and a
coefficient field depending on the two orbit invariants. The same construction
must

1. recover `SO(2)` from the operator/domain pair;
2. generate the weight sectors and two-dimensional quotient PDEs;
3. prune unseen weights by a coercive/Casimir bound;
4. compare a boundary-fitted full 3D method with reduced 2D sector solves at one
   continuum observable and tolerance.

That transfer tests the general claim that groups decompose PDEs by orbit geometry
without presupposing coordinate separability.

```powershell
  physics\mathematical-physics\research-worktable\computation\examples\disk-fixed-accuracy.json `
  --summary
```

```powershell
uv run --directory physics\mathematical-physics\research-worktable\computation `
  --with numpy==2.3.3 --with scipy==1.16.1 `
  python -m unittest check_boundary_fixed_accuracy.py -v
```

residuals, frontier certificate, active unknowns, nonzeros, setup/solve/recovery
times, route decision, and explicit non-certifications.
