# Seed--defect construction calculus

## 1. Inquiry and discriminating alternatives

The requested capability is stronger than a common result schema:

> From typed operator, domain, tensor, preparation, and observable data, generate a
> useful infinitesimal structure or a bounded obstruction without selecting a named
> group or replaying a problem-specific derivation.

The current workbench already maps heterogeneous routes to a `ReductionWitness`,
but its executable discovery boundary selects a schema-specific constructor. This
creates the operative tension:

```text
common witness semantics
does not imply
common generative origin.
```

Two alternatives were kept live for the retrospective probe:

- **A — universal defect generator:** one defect-kernel construction generates the
  candidate space as well as selecting its admissible part across centralizer,
  boundary, and covariance routes.
- **B — seed plus defect compiler:** typed seed functors remain plural, but their
  outputs enter one reusable defect, quotient, closure, and refusal construction.

The probe compares three already supported routes. It is not another physics
example and cannot count as independent transfer evidence for the candidate it
constructs.

## 2. The common linear construction

Let `k` be an exact coefficient field and let `C` be a finite-dimensional candidate
space. Depending on the route, `C` may consist of bounded differential arrows,
vector fields, or endomorphisms of a coefficient fiber. Supply:

```text
SeedPackage = (
  typed problem data X,
  capability and allowed equivalences,
  candidate space C with basis-free origin,
  action rho_i:C -> End(T_i) on each constraint object T_i,
  completeness tag relative to a grammar and budget
)
```

For every required equality construct its residual in a named target `E_i`:

```text
delta_i : C -> E_i,
delta_i(c) = left_i(c;X)-right_i(c;X).                 (1)
```

The admissible infinitesimal space is calculated, not named:

```text
K = intersection_i ker(delta_i).                       (2)
```

If the candidate bracket is defined, compute

```text
kappa(x,y) = [x,y] modulo K,       x,y in K.           (3)
```

Zero `kappa` certifies closure. Otherwise the constructor either closes within the
declared budget, classifies a graded/polynomial outcome, or returns the first
nonclosure obstruction. If `rho_vis:K -> End(H_vis)` is the action on the
observable-visible carrier, then

```text
N = ker(rho_vis),       K_eff = K/N                    (4)
```

is permitted only after verifying that `N` is an ideal. Thus the quotient removes
an ineffective action, not merely inconvenient generators.

For a genuine tensor stabilizer, take tensors
`T_i in V^(tensor q_i) tensor (V*)^(tensor p_i)` and let an endomorphism act on
every slot by the Leibniz rule. Then

```text
delta_T(A) = A dot T.                                  (5)
```

If `A,B` lie in `ker(delta_T)`, the representation law gives

```text
[A,B] dot T
  = A dot (B dot T)-B dot (A dot T)
  = 0.                                                 (6)
```

Hence the simultaneous tensor stabilizer is already a Lie algebra. Equation (6)
is the closure witness; a component nullspace may audit (2), but it is not the
human derivation. Real forms, domains, and global integration remain later
obligations.

## 3. Retrospective cross-route probe

The common target of the probe is the infinitesimal arrow space that preserves all
typed data required by the existing route.

| Route | Seed candidate `C` | Defect map | Kernel/quotient output | Hidden privilege |
| --- | --- | --- | --- | --- |
| filtered centralizer | intrinsic order/covariance modules in `F_m Diff(E)` | principal `{p,q}` followed by lower `[D,Q]` and domain residuals | commuting or normalizing operator module modulo declared trivial functions of `D` | the metric/symbol must generate a complete finite candidate module |
| boundary stabilizer | affine Euclidean Killing fields generated by the metric | interior commutator plus `X rho_G` or boundary-trace leakage | joint operator-domain stabilizer; disk gives `so(2)`, noncircular ellipse gives zero | the affine Killing grammar and quadratic boundary are supplied |
| matrix covariance | current inner derivations `ad(L)` generated from matrix closure | `A dot product`, `A dot pairing`, grading/involution defects | covariant derivations and their visible quotient | `L=Mat_n^0` and `Der(Mat_n)=Inn(Mat_n)` supply the candidates |

All three routes therefore instantiate (1)--(4). Their refusal is also the same
semantic event: the first residual block whose addition lowers the current kernel
or makes the requested capability impossible.

But alternative A fails. The probe did not construct the three candidate spaces
from one operation. It consumed respectively a Killing module, an affine isometry
grammar, and inner matrix derivations. These are the main problem-specific
resources. A generic nullspace routine would unify only the final linear algebra
and would hide rather than solve candidate origin.

Alternative B survives: the reusable object is a two-stage construction.

```text
Seed(data, capability, budget)
  -> natural candidate module C + completeness/naturality certificate

CompileDefects(C, typed constraints, visible carrier, budget)
  -> K, K_eff, closure type, action, certificates, or first obstruction.       (7)
```

The first stage may remain a typed family, but every admitted seed must be natural
under the allowed equivalences, independent of the expected group, and complete
relative to a declared grammar. The second stage has one semantic contract.

This result restricts the global claim: defect compilation is a general
**selection and completion layer for finite linearized grammars**, not a universal
source of useful variables for every PDE. Factorization, spectral projectors, and
observable-cyclic closure are not promoted to instances until an explicit map to
(7) preserves their semantics.

## 4. Frozen local contract `C_G0_v1`

### Claim dimensions

1. **Construction:** unchanged `CompileDefects` semantics covers finite
   centralizer, boundary-stabilizer, and natural-tensor stabilizer inputs.
2. **Transfer:** a held-out tensor grammar outside full matrix inner derivations
   produces a Lie/graded algebra or an informative obstruction without a group
   label.
3. **Use:** its output composes with a `ReductionWitness` for one named observable.
4. **Leverage:** complete seed, kernel, closure, recovery, and certification cost
   is smaller in at least one declared measure than coordinate or named-group
   enumeration.

### Admitted domain

- exact characteristic-zero coefficients;
- finite candidate modules and finite lists of linear covariance, commutator, or
  boundary defects;
- supplied actions on typed tensors, domains, or filtered operator layers;
- explicit equivalence, visible carrier, coefficient grammar, zero policy, and
  resource budget.

Nonlinear determining equations, arbitrary jet pseudogroups, infinite-dimensional
closure, analytic group integration, and automatic self-adjointness are outside
`C_G0_v1`.

### Frozen interface

```text
CompileDefects(seed_package, constraints, visible_action, budget)
  -> {
       admissible basis and dimension,
       independent residual blocks and rank drops,
       ineffective ideal and effective quotient,
       closure presentation or nonclosure residual,
       action consumed by witness construction,
       completeness/naturality/cost certificates,
       exact obstruction or unresolved-within-budget result
     }.
```

Problem adapters may construct tensors and actions. They may not provide the
expected algebra, its dimension, a preferred kernel basis, or case-named repair
rules.

### Falsifiers

- a bench requires changing the core defect, quotient, or closure semantics rather
  than supplying typed adapter data;
- the seed input encodes the expected algebra or basis;
- the constructed kernel fails an existing route equality or domain condition;
- the claimed effective quotient is not an ideal quotient;
- held-out transfer needs the full-matrix/inner-derivation identity;
- construction and recovery merely relocate the baseline work. The last falsifies
  leverage, not mathematical construction.

### Bench family and independence

- **retrospective regression:** bounded quadratic centralizer;
- **cross-family regression:** disk/ellipse boundary stabilizer;
- **restricted covariance regression:** matrix-symbol pairing, explicitly marked
  as dependent on the seed lineage;
- **held-out transfer (former F8):** a finite natural-tensor grammar not generated
  by a full associative matrix algebra;
- **adversarial refusal:** incompatible tensor or boundary/domain data;
- **use:** compose the held-out action with one observable witness and compare the
  complete route.

The held-out transfer must be chosen and frozen before its result is calculated.
It may not be used to amend `C_G0_v1` and then count as transfer for that revision.

### Promotion and stop conditions

Promote the construction dimension only if the first three routes factor through
the frozen interface and the held-out input transfers or refuses for a predicted
reason. Promote the use dimension only after witness composition. Promote leverage
only after the whole-route comparison.

Reject or split the calculus if preserved semantics are incompatible. Restrict it
if a counterexample identifies a smaller domain. Stop after disposition when
further examples cannot change one of these dimensions.

## 5. Constructor pseudocode

```text
compile_defects(seed_package, constraints, visible_action, budget):
    verify types, coefficient field, equivalences, and budget
    C = seed_package.candidate_module
    verify seed naturality and relative-completeness claim

    K = C
    ledger = []
    for constraint in constraints:
        delta = construct_residual_map(K, constraint)
        require common residual target and exact zero policy
        K_next = kernel(delta restricted to K)
        ledger.append(constraint, rank(delta), K -> K_next)
        K = K_next
        if required capability is impossible:
            return Obstruction(first_failed_constraint, ledger)

    N = kernel(visible_action restricted to K)
    require bracket(K,N) is contained in N
    K_eff = quotient(K,N)

    closure = certify_or_generate_closure(K_eff, budget)
    if closure exceeds budget:
        return UnresolvedWithinBudget(K_eff, first_closure_residual, ledger)

    return ConstructedAction(
        K, K_eff, closure, ledger,
        seed_certificate, quotient_certificate, cost
    )
```

The retained human object is the seed origin, constraint list, kernel/quotient
universal properties, closure law, and recovery map. Exact matrices, row reduction,
and tensor contractions belong to the certificate substrate.
