# Radial–Laurent extension of the quadratic centralizer

## 1. Obstruction being removed

The polynomial `E^2` generator produced a complete quadratic candidate module but
could not admit Coulomb coefficients.  The earlier Coulomb bench admitted the
potential but selected the successful Runge--Lenz covariance type by hand.  This
extension combines their strengths:

```text
complete metric-generated module + exact radial coefficient algebra
  -> coefficient-selected Runge--Lenz operators.                     (1)
```

The first implementation horizon was the punctured Euclidean plane. The same
coefficient construction now has a three-dimensional realization, where the
metric-generated module has a nontrivial presentation quotient.

## 2. Exact coefficient algebra

Introduce `s=x^2+y^2` and the finite-support algebra

```text
A_rad=Q[x,y,s^(1/2),s^(-1/2)]/(s-x^2-y^2).               (2)
```

Orient the defining relation as

```text
x^2 -> s-y^2.                                            (3)
```

Every expression then has a canonical representative with `x`-degree below two.
Differentiation is generated by

```text
partial_x s^q=2q x s^(q-1),
partial_y s^q=2q y s^(q-1),                              (4)
```

followed by (3).  This supplies an exact zero policy for the compatibility map,
lower-term reconstruction, differential-operator composition, and commutator
certificates.  It is not a general-purpose simplifier.

## 3. The same complete module is reused

The metric still generates the three first-order Killing vectors and complete six
rank-two Killing tensors.  For each supplied `V in A_rad`, the tool computes

```text
X(V)=0                                      first-order symmetries,
B_V(K)=d(K dV)=0                            quadratic symbols,       (5)
dW=K dV                                    lower-term lift,
[H,-1/2 partial_i K^ij partial_j+W]=0       quantum certificate.     (6)
```

Thus admitting `1/r=s^(-1/2)` changes only the coefficient substrate.  It does not
insert new candidate tensors or a Coulomb-specific operator template.

## 4. Lower terms without an integration catalogue

For each generated closed one-form in the current inputs, the executable constructs
a finite monomial carrier from inverse derivative incidences, solves the exact
derivative map, and returns `W` only after both partial derivatives reproduce the
supplied one-form.  Failure to reconstruct inside that carrier is a structured
refusal; the implementation does not claim a complete integration algorithm for
all closed forms in `A_rad`.  In particular, the terms `-x/r` and `-y/r` are
generated by this solve; they are not present in the input or Killing module.

## 5. Returned capability and boundary

The extension returns first- and second-order compatibility matrices, their exact
kernels, lifted operators, formal quantum commutators, and the coefficient normal
form.  Its completeness remains relative to the same scalar even order-two class.

The puncture is excluded from the formal core.  Self-adjoint extensions, strong
commutation, bound-state completeness, and topology around `r=0` are not certified
by the coefficient algebra. Arbitrary rational denominators, logarithmic lower
terms, dimension-generic module generation, magnetic curvature, and spinors require new typed
extensions.

The [complete Coulomb transfer](../benchmarks/coulomb-e2-complete.md) consumes this
generator, closes the generated operators, and recovers the negative-energy
representation spectrum.  This is the rejoin edge to the bilateral group--PDE
spine. The [three-dimensional extension](e3-quadratic-centralizer.md) separately
constructs the redundant `E^3` module, selects all three Runge--Lenz directions,
and rejoins the `so(4)` spectrum route.
