# Result 27: sparse network-elimination order

## Tension

`C-network-v1` proves that hidden linear states can be condensed, but its block
inverse is not yet a human computation route. Expanding the full Schur complement
can destroy sparsity and keep many expressions live. A useful exam operator must
say which local state to remove next, show the update, retain recovery, and expose
the work it creates.

## Construction `C-order-v1`

For a reciprocal exact response `Kx=f`, eliminating one hidden state `h` with
provably nonzero pivot `K_hh` updates the remaining system locally:

```text
K'_ij = K_ij - K_ih K_hj/K_hh,
f'_i  = f_i  - K_ih f_h/K_hh,
x_h   = f_h/K_hh - sum_j (K_hj/K_hh)x_j.
```

Only current neighbors of `h` can change. The planner calculates for every
admissible hidden state:

```text
(new fill edges, active-neighbor count, declared-order rank).
```

The `min_fill` strategy greedily chooses the lexicographically smallest tuple.
After all internal states are removed, their local recovery equations are replayed
in reverse. Certificates require the sequential boundary law to equal the exact
one-shot block condensation, reverse recovery to equal its affine recovery map,
and every scalar pivot to be provably nonzero.

The inspectable work ledger counts each affected symmetric coefficient once:
`d(d+1)/2` updates for a pivot with `d` active neighbors. It adds `d` source
updates only when the eliminated source is nonzero. Fill counts previously zero
neighbor-pair couplings made nonzero by the update.

An otherwise identical central-source fixture raises the minimum-fill ledger from
5 to 7, exactly the two affected boundary-source corrections.

## Frozen distinguishing bench

The bench has two boundary nodes, one central hidden node, and two grounded hidden
branches. The declared hidden order begins with the center.

| Strategy | Order | New fill edges | Nonzero local updates |
| --- | --- | ---: | ---: |
| declared | center, leaf 1, leaf 2 | 6 | 19 |
| greedy minimum fill | leaf 1, leaf 2, center | 1 | 5 |

Both routes return the same two-boundary matrix and the same three hidden states.
The sparse order transfers unchanged when the area semantics change from voltage
to displacement. Thus the planner reacts to current topology rather than a problem
identifier or an encoded equivalent coefficient.

An adversarial reciprocal fixture has invertible internal block
`[[0,1],[1,0]]` but no nonzero scalar diagonal pivot. One-shot condensation
succeeds; `C-order-v1` returns `no_provable_scalar_pivot`. A nonreciprocal matrix
and a step-budget overflow are also explicit refusals.

## Disposition

`C-order-v1` is **supported-bounded as a structurally cheaper exact execution
route** on the frozen reciprocal sparse-network bench. It converts a block formula
into reproducible local steps, reduces this bench's fill and update counts, and
preserves exact boundary and recovery semantics.

The greedy rule is not claimed globally fill-optimal. Update count is a structural
ledger, not elapsed time, memory burden, error rate, or learning cost. The planner
does not recognize a matrix from a diagram, exploit handwritten series/parallel
shortcuts, handle nonreciprocal systems, use block pivots, or prove that a student
will choose the same order reliably. Human exam savings therefore remain open.

The structural-to-human bridge is continued in
[Result 28](deductive-network-human-boundary-28.md), which charges pivot recognition
explicitly and constructs the positive-weight break-even region. The next cost/use
discriminator is a frozen matched problem in which direct nodal equations and the
printed local strip target the same observable. The independent mathematical
frontier remains a reduction generated by a supplied conservation or symmetry
action.
