# Result 28: deductive network human-cost boundary

## Tension

Lower fill and fewer symbolic updates do not imply that a person is faster. The
sparse route must first recognize the representation and repeatedly choose a
pivot. Treating that work as free would convert a favorable implementation count
into a circular human claim. Conversely, requiring learner observations before any
reasoning would discard the exact conditional information already available.

## Construction `C-network-human-v1`

The constructor takes one admitted reciprocal network and generates both the
declared and greedy sparse scalar plans. It lowers each plan into the existing
handwritten route ledger:

```text
(relations selected,
 hidden quantities,
 peak live relations,
 symbolic actions,
 branch checks,
 representation changes,
 return checks).
```

Every nonzero local matrix/source correction becomes one atomic symbolic subject.
The sparse route is charged one representation action for every current-fill pivot
decision. Both routes retain the same problem, physical target, execution
substrate, hidden meanings, and return check.

For the frozen branched network the generated ledgers are

```text
declared = (1,3,5,19,0,0,1),
sparse   = (1,3,5, 5,0,3,1),
delta    = (0,0,0,-14,0,3,0).
```

Both routes initially carry the same five node-balance relations. The structural
neighbor-width reduction from four to two is real, but it is not renamed as fewer
live relations and therefore does not enter this inherited cost model.

With strictly positive but otherwise unspecified axis weights, the exact
break-even condition is therefore

```text
3*w_representation_changes
  < 14*w_symbolic_actions.
```

This is the deductive speed theorem: within the declared additive model, sparse is
cheaper exactly in this region. A unit-weight sensitivity probe selects sparse; a
probe assigning weight six to representation changes selects declared order.
Neither probe estimates a real learner.

## Direct-gate transfer

On a one-hidden-node chain, declared and minimum-fill orders coincide. The sparse
route has identical execution work and one additional pivot-selection action:

```text
delta = (0,0,0,0,0,1,0).
```

The constructor returns `always_direct` for every strictly positive weight profile.
This negative transfer prevents the framework from recommending abstraction when
it cannot remove work.

## Certificates and refusals

The constructor certifies that both plans return the same boundary relation, their
symbolic route units equal the generated local-update counts, every sparse pivot
decision appears as recognition/setup debt, and the break-even boundary is derived
from the returned ledgers. A scalar-planning obstruction prevents construction of
a cost claim rather than silently comparing incomplete routes.

Every result also returns the irreducible evidence obligations:

```text
independent route-key review,
matched correct execution,
participant-clustered timing,
delayed retention,
unseen-topology transfer.
```

## Disposition

`C-network-human-v1` is **supported as an exact model-relative admission
boundary**. It proves when the sparse action ledger is cheaper and proves a direct
gate when recognition is pure overhead. It also makes the inference boundary
executable: speed remains `conditional_weights_unmeasured` on the branched case,
and learnability remains `human_observations_required` everywhere.

Finite instructions, local decisions, reverse recovery, relabeling invariance, and
cross-area transfer are deductive cognitive affordances. They do not establish
human comprehension, reliable recognition, elapsed-time improvement, retention,
or transfer. Those quantities cannot be recovered from algebraic certificates.

The next admissible network step is empirical construction: freeze matched direct
and sparse tasks, obtain independent route-key review, then collect
participant-clustered immediate, delayed, and unseen-topology observations. Until
then the worktable may state a conditional theorem but not a human-speed or
learnability result.
