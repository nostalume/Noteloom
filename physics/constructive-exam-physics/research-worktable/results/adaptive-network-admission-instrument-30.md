# Result 30: adaptive network-admission instrument

## Tension

`C-network-study-v1` can compare execution under assigned direct and sparse routes,
but assignment removes the very judgment required by an adaptive exam tool. It
cannot show whether a learner knows when sparse reduction may pay, when it is pure
overhead, or when the scalar planner is outside its domain.

A binary direct/sparse key would also be invalid. On every positive structural
example, `C-network-human-v1` returns a conditional inequality because sparse
removes symbolic updates while adding representation-selection work. Without
measured human weights, “sparse” is not an exact correct answer.

## Construction `C-network-admission-v1`

The new instrument therefore constructs a three-valued decision from the exact
positive-weight boundary:

```text
always_direct       -> direct_gate
conditional         -> conditional_candidate + exact inequality
planner obstruction -> refuse + typed obstruction code
```

`conditional_candidate` means sparse can be cheaper in part of positive-weight
space; it does not predict that a learner will be faster. `refuse` applies only to
this reciprocal scalar strip, not to the solvability of the physical problem by
another method.

The frozen bench has nine tasks:

| Phase | Classes | Topology scope |
| --- | --- | --- |
| `immediate_unassisted` | one gate, candidate, refusal | three trained families |
| `delayed_same_topology` | one gate, candidate, refusal | same families, changed coefficients |
| `unseen_topology` | one gate, candidate, refusal | two-hidden path, split hub, zero-pivot block |

The unseen candidate returns
`4*w_representation_changes < 17*w_symbolic_actions`; the unseen direct path has no
elimination saving; the reciprocal hidden block `[[0,1],[1,0]]` is invertible but
has no provable scalar diagonal pivot. These outcomes discriminate transfer of the
decision rule rather than memory for a single star diagram.

Sequences `A1` and `A2` reverse order within each phase. No task receives an
assigned route and no scored phase shows the training sheet. Each participant
selects `direct_gate`, `conditional_candidate`, or `refuse`, gives a structural
reason, and stops before solving the terminal value.

## Observable and analysis contract

The loader restores phase, task, and exact expected decision from the frozen
schedule. It refuses unknown choices, assignment tampering, invalid delay,
duplicate slots, mixed sequences, or inconsistent phase sessions. Immediate,
delayed, and unseen sessions remain distinct, with unseen recognition later than
delayed recognition.

A participant-phase cluster exists only when all three decision classes are
complete. Accuracy and mean decision time are first computed within that cluster,
then averaged across participants. Individual task decisions cannot inflate the
learner count. Selection counts remain visible so an always-gate, always-candidate,
or always-refuse response pattern cannot hide inside aggregate accuracy.

The N2 recognition cohort must be disjoint from the N1 execution cohort within a
study wave. Otherwise N2 vocabulary primes assigned execution, or N1 execution
trains later recognition. The overlap refusal is executable.

## Independent key preflight

Every prompt requires two qualified reviewers who independently classify it while
blind to the authored key and peer work. They judge both exact-key agreement and
prompt ambiguity. One admitted disagreement or ambiguity yields
`revision_required`; insufficient admitted positive reviews yield
`additional_review_required`; only complete agreement yields `ready_for_pilot`.

## Current disposition

Both checked-in TSVs contain only headers. The audit returns:

```text
tasks:          9
decision keys:  3 direct_gate, 3 conditional_candidate, 3 refuse
key preflight:  additional_review_required
learner data:   unobserved
recognition:    not_evaluated
retention:      not_evaluated
transfer:       not_evaluated
```

`C-network-admission-v1` closes the adaptive-recognition acquisition gap, not the
human-evidence gap. A pilot can estimate feasibility and participant-clustered
accuracy/time only after independent review. Confirmatory thresholds and a
held-out cohort remain necessary before any learnability disposition changes.
