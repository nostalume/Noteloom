# Constructive Exam Physics

This project joins a learner-facing physics review with an executable research
worktable. Its organizing question is not “Which chapter contains the formula?”
but:

> What is the smallest justified calculation that returns the requested physical
> observable without losing units, regime, direction, boundary, or branch meaning?

Physics knowledge is not eliminated. The solver first constructs an area-specific
packet of objects, laws, assumptions, and conventions. Only then may a shared
mathematical operator remove hidden quantities. A return ledger reconnects the
reduced result to the original physical target.

The stable route is

```text
TARGET -> PHYSICAL PACKET -> SLICE -> DIRECT GATE
       -> OBSTRUCTION -> OPERATOR -> RETURN -> CHECK
```

The direct gate matters: when a short familiar derivation already closes, use it.
The structural operators are valuable when they expose or remove a real
obstruction, make a transfer reproducible, or turn a failure into a typed refusal.

## Claim boundary

The delivered capability is a bounded, target-conditioned constructor and a
review/verification method. Exact constructions and named transfers are supported
only inside their declared physical and mathematical contracts. The checked-in
human instruments are unpopulated, so faster solving, learning, retention, and
transfer are not established. Universal physics coverage and novelty are not
claimed; consult the canonical graph for the dimension-by-dimension disposition.
